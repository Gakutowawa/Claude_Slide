# Slide Framework

BCG公共系スタイルのスライド作成フレームワーク（デザイン規約＋ストーリー構築ルール）を管理するリポジトリです。
Claudeにスライド作成を依頼する際のプロンプト、デザイン規約、参考資料をコードとして体系化し、継続的に改善・拡張していくことを目的とします。

## 目的

- スライドのデザイン／ストーリー構築ルールを「コード」として明文化する
- Claudeに出すスライド作成プロンプトをバージョン管理する
- 参考スライド（PDF等）を一元管理する
- 使うたびにルールを継ぎ足し、自分仕様にアップデートしていく

## フォルダ構成

```
slide-framework/
├── README.md              # このファイル
├── prompts/                # Claudeに出すスライド作成プロンプト
│   └── slide_creation_prompt.md
├── rules/                   # デザイン規約・ストーリー構築ルール
│   ├── layout_rules.md      # レイアウト規約
│   └── scqa_story_rules.md  # 空雨傘・SCQAのストーリー構築ルール
├── references/               # 参考スライド（BCG公共系PDF等）
└── outputs/                   # 実際に作成したスライドの保管
```

## ルール概要

### レイアウト規約
- 冒頭にエグゼクティブサマリー（ストーリーを過不足なく網羅）
- 各スライド：左上にスライドタイトル、中央上に主メッセージ（大きめ）
- ページ番号を記載
- 下部に注釈・出典を記載

### ストーリー構築（空・雨・傘 × SCQA）
0. ビジネス目的の定義
1. 背景・現状（S）
2. 課題（C・Q）
3. 解決策（A）
   - ロジックツリーで施策出し
   - 比較軸で評価
   - What to do → How to do
   - 必要に応じて優先度・手順・実行ポイント・スケジュール

### 示唆の書き方
示唆を書く場合は、妥当な理由と裏付け分析をセットにする（仮説思考）。

## 使い方

1. `prompts/` 内のプロンプトをコピーしてClaudeに投げる
2. `rules/` のルールに沿って出力を確認・修正依頼
3. 良い型ができたら `rules/` や `prompts/` を更新してコミット
